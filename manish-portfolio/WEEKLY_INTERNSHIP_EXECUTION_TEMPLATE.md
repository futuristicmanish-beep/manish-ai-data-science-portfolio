## BALANCING ACT TIPS

### When You're Busy (Exams, Assignments)
**Minimum viable week:**
- 3 x 1-hour sessions
- Focus: DSA practice only
- Goal: Maintain streak, don't lose momentum

### When You Have More Time (Breaks, Weekends)
**Accelerated week:**
- Complete 1 full project
- Intensive learning (new skill)
- Multiple applications
- Portfolio polish

### When Feeling Overwhelmed
**Reset week:**
- Focus on one thing only
- Complete it well
- Build confidence back
- Plan better for next week

### When Making Great Progress
**Double down:**
- Continue what's working
- Document your system
- Help others (teach what you learned)
- Stay humble, keep learning

---

## AVOIDING BURNOUT

### Warning Signs:
- Dreading daily practice
- Rushing through without learning
- Constantly distracted
- Comparing to others negatively
- Skipping multiple days

### Prevention:
- **Rest days:** 1 day off per week is okay
- **Variety:** Mix activities (code, learn, apply)
- **Celebrate wins:** Acknowledge progress
- **Realistic goals:** Don't overcommit
- **Enjoy process:** Find joy in learning

### Recovery:
- Take 2-3 days complete break
- Come back with smaller goals
- Focus on one thing you enjoy
- Rebuild habit gradually
