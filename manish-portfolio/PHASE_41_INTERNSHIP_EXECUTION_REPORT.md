## APPLICATION WORKFLOW SUMMARY

**10-Step Process:**
1. **DISCOVER** → Find opportunities on job boards, company sites
2. **CHECK REQUIREMENTS** → Analyze fit (60%+ required skills match)
3. **SELECT ROLE** → Match to readiness tier
4. **SELECT RESUME** → Choose variant A/B/C
5. **CUSTOMIZE** → Tailor resume and cover letter
6. **APPLY** → Submit with all materials
7. **RECORD** → Track in application tracker
8. **FOLLOW UP** → Email after 7-14 days if no response
9. **PREPARE** → Interview prep if response received
10. **REVIEW** → Learn from each application

**Quality Metrics:**
- 2-4 applications/week (quality over quantity)
- 15-30 min research per company
- Customized materials for each application
- Follow-up system in place

**When NOT to Apply:**
- Senior roles or 3+ years experience required
- <40% match on required skills
- Poor company culture fit
- Rushed application without time to customize
